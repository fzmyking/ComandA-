O que é o ComandAí?

Um curso prático para aprender comandos do Minecraft do zero e avançar até os command blocks. Cada módulo apresenta uma ferramenta, explica como ela funciona e mostra como usar na prática.

O que você vai aprender

  • ✓Entender a estrutura dos comandos
  • ✓Usar alvos, itens e efeitos
  • ✓Criar ações com comandos
  • ✓Automatizar ideias com command blocks
